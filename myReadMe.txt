init creates a git repo for a directory
repository: a place to store versions of a directory, stores past versions
add: adds working directory files to temp storage place
commit: pushes temp storage space to git repo
checkout: pulls data from Git repo to working directory

remote: establishes connection between git repo and GitHub repo
pull: pulls data from GitHub repo to Git repo
push: pushes data from git repo to GitHub repo
clone: pulls current version and all past versions of GitHub repo to git repo
